AURA-MFP

Undergraduate Independent Research into High Performance Computing

Closed-Loop Multi-Fidelity PV Simulation

AURA-MFP is a closed-loop model predictive control framework for photovoltaic systems. Edge sensors (Pico RP2040 + Raspberry Pi 3B+) feed real-time weather data into a DualHead PINN orchestrator, which predicts panel temperature and selects the optimal fidelity tier from an 8-tier Fortran multi-fidelity solver stack (simv0–simv4). The solver output drives actuator commands, completing the control loop. Validation is in progress against the Sandia PVMC dataset.

Multi-Fidelity Architecture

AURA-MPC implements an 8-tier fidelity ladder. The DualHead PINN orchestrator (simv4) selects the optimal tier at runtime based on current operating conditions.

Tier Model Suited For
simv0 Baseline single-diode Clear-sky, low-accuracy path
simv1 Faiman thermal + BTE-NS-T High-fidelity gold standard
simv1b simv1 + spectral inversion Spectral mismatch correction
simv2 Sandia empirical PV model Broad operating range
simv2b Sandia + IIR filter Noisy/rapidly-changing input
simv3 Sandia + energy-balance ODE High-accuracy thermal tracking
simv3b simv3 + Fuentes thermal corr. Full thermal mass correction
simv4 Fortran + PINN weights router Maximum fidelity, PINN-guided

< 5 ms inference
DualHead PINN: predicts Tpanel and emits a 5-way routing probability vector (simv0–simv4). Weights embedded at compile time via pinn_weights_module.f90.
Closed-Loop Data Flow
Edge → PINN → Fortran
Pico RP2040 + Pi 3B+ sensors → DualHead PINN orchestrator → Fortran multi-fidelity solver (simv0–simv4) → actuator commands
