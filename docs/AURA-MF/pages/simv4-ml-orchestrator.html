Executive Summary

SimV4 is the top-tier solver in AURA-MFP. Rather than solving the thermal/spectral model itself, it runs a compact Physics-Informed Neural Network (PINN) whose weights are embedded at compile time via pinn_weights_module.f90. SimV4 emits a 5-way routing probability vector recommending which of SimV0–SimV4 best matches the current operating regime, plus a predicted panel temperature and spectral mismatch factor. Forward-pass cost: < 5 ms (pure Fortran, zero file I/O at runtime).

DualHead PINN Architecture

Network Design

The PINN uses a dual-head architecture:

  • Temperature head: predicts $T_{\text{panel}}$ [°C] from weather inputs
  • Routing head: emits a 5-way softmax probability vector $$\mathbf{p} = [p_{\text{LOFI}},\; p_{\text{SimV1}},\; p_{\text{SimV2}},\; p_{\text{SimV3}},\; p_{\text{SimV4}}], \quad \sum p_i = 1$$

Network Architecture

Input (7 features) → Hidden (16 neurons, tanh) → Hidden (16 neurons, tanh) → Dual output heads

Input features: $[G_{\text{poa}},\; T_{\text{amb}},\; u_\infty,\; \text{CC},\; \phi,\; \lambda,\; \text{img\_features}[1..5]]$

JSON Interface

Input / Output Contract

Input JSON:

{"t_s": float, "G_poa": float, "T_amb": float, "WS": float,
 "CC": float, "lat": float, "lon": float,
 "img_features": [f1, f2, f3, f4, f5]}

Output JSON:

{"T_panel_predicted": float,
 "routing_probs": {"LOFI": p0, "SIMV1": p1, "SIMV2": p2,
                   "SIMV3": p3, "SIMV4": p4},
 "spectral_mismatch_factor": float,
 "efficiency_derating": float,
 "inference_time_ms": float,
 "confidence": float}

where confidence = max(routing_probs).

Spectral Mismatch Factor

AM1.5-Normalised Spectral Mismatch

SimV4 computes the spectral mismatch factor using the loaded silicon optical LUT (Green & Keevers 1995) and the AM1.5 reference spectrum (ASTM G173-03):

$$M_{\text{spectral}} = \frac{\displaystyle\int E(\lambda) \cdot \text{EQE}(\lambda) \, d\lambda}{\displaystyle\int E_{\text{AM1.5}}(\lambda) \cdot \text{EQE}(\lambda) \, d\lambda}$$

Computed via cubic spline interpolation of the silicon optical LUT over the AM1.5 integral (280–4000 nm range, 361 points).

Weight Embedding and Inference

Compile-Time Weight Embedding

PINN weights are generated offline by modules/pinn-aura-mfp/scripts/export_weights_to_aura_mfp.py, which writes every weight and bias as named Fortran constants into pinn_weights_module.f90. This file is compiled directly into the SimV4 binary, making inference a pure Fortran forward pass with zero file I/O at runtime.

Forward pass cost: < 5 ms (deterministic; --test mode completes in < 5 ms)

Architecture: 2 × 16 hidden neurons (tanh) — compact by design to enable Fortran deployment

Data Requirements

Required Data Files

SimV4 requires three data files at startup:

FileContentsPoints
data/atmospheric_luts/am15_global.csv ASTM G173-03 AM1.5 spectrum 510
data/material_properties/silicon_optical.dat Green & Keevers (1995) Si optical properties 361
data/geographic/locations.csv Geographic reference data —

If any file is missing, SimV4 emits STOP 1 with a descriptive error rather than silently falling back.

Key Contributions

  1. First Fortran-embedded PINN router for multi-fidelity PV simulation (zero runtime I/O)
  2. Compile-time weight embedding via pinn_weights_module.f90 (no Python dependency at inference)
  3. Dual-head architecture simultaneously predicts panel temperature and optimal fidelity tier
  4. Spectral mismatch factor from AM1.5/Si LUT (cubic spline, full 280–4000 nm range)
